# Conversor de Unidades

## Descripción

Este proyecto consiste en una aplicación de escritorio desarrollada en C# utilizando Windows Forms. Su objetivo es permitir la conversión entre diferentes unidades de medida mediante una interfaz gráfica sencilla e intuitiva.

El usuario introduce un valor numérico, selecciona el tipo de conversión y el sistema muestra el resultado correspondiente.

## Funcionalidades

- Conversión de kilómetros a millas.
- Conversión de millas a kilómetros.
- Conversión de grados Celsius a Fahrenheit.
- Conversión de grados Fahrenheit a Celsius.
- Validación de datos ingresados por el usuario.
- Limpieza de los campos del formulario.
- Opción para cerrar la aplicación.

## Ejecución del proyecto

1. Clonar o descargar el repositorio.
2. Abrir la solución en Visual Studio.
3. Compilar el proyecto.
4. Ejecutar la aplicación presionando **F5** o **Ctrl + F5**.
